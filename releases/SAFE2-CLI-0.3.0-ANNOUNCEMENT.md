# SAFE2 CLI 0.3.0 announcement drafts

Publish only after the update is merged and available. Main-branch links below become current after merge. Do not imply a PyPI release until publishing succeeds.

## LinkedIn / company post

🟠 An agent saying “done” should start an evidence check—not end one.

SAFE2 CLI 0.3.0 adds task receipts: a practical way to connect declared outcomes to artifacts, test results, tool outcomes, and per-task resource declarations.

Before: reported completion and usage were difficult to inspect together.
After: humans and agents can check explicit criteria, capture fresh pytest evidence, recheck saved results without rerunning code, and distinguish reported usage from estimates and unknowns.

🟢 Supported. 🟠 Contradicted. ⚪ Unverifiable.

Those are evidence assessments—not a claim to measure an agent's intent or certify its honesty. A test pass is not whole-task acceptance. A signature authenticates bytes, not truth. We keep those boundaries visible.

The framework remains AI SAFE² v3.1 with 161 controls. This update strengthens the CLI evidence workflow.

[See the walkthrough](https://github.com/CyberStrategyInstitute/ai-safe2-framework/blob/main/docs/TASK-RECEIPTS.md)

The important distinction: a missing receipt is not proof an agent lied. We need tools that preserve uncertainty rather than turn it into a confident score. This release makes narrow claims inspectable; trusted execution and billing reconciliation are separate next steps.
