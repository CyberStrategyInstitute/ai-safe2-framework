# SAFE2 CLI Agent Entry Point

Read the repository-root `AGENTS.md` first. For SAFE2 CLI work, parse
`safe2-docs.manifest.json`, then read `README.md` and `docs/README.md`.

- JSON artifacts are canonical; Markdown and HTML cards are projections.
- Preserve facts, declarations, assumptions, unknowns, and verification results
  as distinct states.
- Do not convert a generated score or receipt into human approval, conformance,
  release, deployment, or risk acceptance.
- CLI-owned guidance belongs under `safe2/`; historical release records belong
  under `releases/`; shared assurance methods belong under `docs/`.
- Update code, schemas, tests, documentation, examples, and manifests together.
