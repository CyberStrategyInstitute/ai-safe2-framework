- Before-and-after evidence graph

## 1.0 criteria

- Stable schemas with migration documentation
- At least two interchangeable semantic-review providers
- Independent security review of the distribution
- Reproducible acceptance suite
- Documented privacy and data-boundary behavior
- Signed release artifacts and software bill of materials
- Proven upgrade and rollback path
