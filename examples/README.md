## Purpose

The examples directory shows how AI SAFE² controls can be operationalized around real agent frameworks, automation systems, gateways, and security tooling.

Examples demonstrate implementation patterns. They do not create framework conformance merely by being copied or installed. A deployment must satisfy applicable control outcomes and evidence requirements in its own operating context.
